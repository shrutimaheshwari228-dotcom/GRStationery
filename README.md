# GR & Company Stationery

Official website and digital product catalogue for **GR & Company Stationery**, located in Jaipur.

## Features
- **Brand-First Product Catalogue**: Explore stationery by top brands like Nataraj, Apsara, Faber-Castell, DOMS, Camlin, Classmate, Cello, Linc, Montex, and Reynolds.
- **WhatsApp Enquiries**: Direct product-specific WhatsApp enquiry integration.
- **Dark Premium Aesthetic**: Tailored Old Jaipur + Dark Stationery aesthetic.
- **Responsive Design**: Optimized across mobile, tablet, and desktop viewports.

## Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Routing**: [React Router](https://reactrouter.com/) (HashRouter for seamless GitHub Pages compatibility)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: GitHub Pages via GitHub Actions
